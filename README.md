# Anomaly detection using surprisals

Paper by [Rob J Hyndman](https://robjhyndman.com) and David T Frazier

1. First install all packages using `renv::restore()`.
This step is to ensure we are both using the same package versions for this project, regardless of what we use elsewhere.

2. Then compile the project using `targets::tar_make()`. This runs all the code for the examples, and compiles the quarto file.
